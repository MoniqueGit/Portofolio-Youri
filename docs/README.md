# Arborescence du site

Livrable pour le cours : architecture du portfolio, avec les compétences du
BUT GEII parcours ESE.

## Fichiers

| Fichier | À quoi ça sert |
|---|---|
| `arborescence-portfolio.drawio` | **Le fichier à rendre et à modifier.** S'ouvre sur [app.diagrams.net](https://app.diagrams.net) (Fichier → Ouvrir depuis → Appareil) ou dans VS Code avec l'extension *Draw.io Integration* |
| `arborescence-portfolio.svg` | Vectoriel : à insérer dans un rapport, s'imprime sans pixeliser |
| `arborescence-portfolio.png` | Aperçu rapide (1455 × 2634 px) |

## Ce que le diagramme montre

Les deux pages du site (`/` et `/collins`), leurs sections, et pour chaque
projet académique : les pièces de son dossier technique et les apprentissages
critiques du référentiel qu'il fait travailler.

## Le régénérer après une modification du site

Le diagramme est écrit à la main dans `docs/arborescence-portfolio.drawio`.
Si la structure du site change, le plus simple est de l'ouvrir sur
app.diagrams.net et d'y ajouter la boîte manquante : la mise en page est un
arbre de gauche à droite, une colonne par niveau de profondeur.

## Code couleur

Il reprend celui du site : cyan pour la structure, magenta pour ce qui est en
cours (années de BUT, apprentissages critiques), ambre pour ce qui reste à
produire (les pièces de dossier).
